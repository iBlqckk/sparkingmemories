# Sparking Memories

Crea una página web de cumpleaños como regalo emotivo para mi papá, 

electricista, que cumple 57 años el 18 de agosto. Quiero un sitio de 

una sola página (landing page), cálido, personal y con un toque 

relacionado a la electricidad (su oficio), sin verse infantil.

ESTRUCTURA:

1. Sección Hero (portada):

   - Título grande: "¡Feliz Cumpleaños, Papá!"

   - Subtítulo: "57 años iluminando nuestras vidas"

   - Fondo con un efecto sutil de chispas o destellos eléctricos 

     (líneas tipo circuito, pequeños rayos animados, partículas 

     doradas) en tonos cálidos (amarillo/naranja/ámbar) combinados 

     con azul oscuro o negro, como si fuera un "panel eléctrico" 

     elegante

   - Botón "Ver mi sorpresa" que hace scroll suave a la siguiente sección

2. Sección "Sobre ti":

   - Un texto breve y emotivo sobre él: su oficio como electricista, 

     su esfuerzo, dedicación y cómo ha sido un ejemplo para la familia

   - Ícono o ilustración sutil de herramientas eléctricas (bombillo, 

     destornillador, cables) como decoración

3. Galería de fotos:

   - Espacio para 4 fotos en un grid o carrusel elegante

   - Cada foto con un marco tipo "polaroid" o con bordes suaves y 

     sombra, y espacio debajo para una pequeña frase o fecha

   - Deja las fotos como placeholders/imágenes de ejemplo para que 

     yo las reemplace después fácilmente

4. Sección de mensaje final:

   - Una carta o dedicatoria personal de cumpleaños (dejar un texto 

     de ejemplo editable)

   - Efecto de confeti o luces al cargar esta sección

5. Footer:

   - Frase de cierre tipo "Con todo mi cariño, [tu nombre]"

   - Fecha: 18 de agosto

ESTILO GENERAL:

- Diseño moderno, responsive (se vea bien en celular)

- Paleta de colores: negro/azul oscuro + dorado/ámbar + blanco, 

  evocando electricidad de forma elegante, no infantil

- Tipografía cálida y legible, con detalles tipo destello (☇) en 

  algunos títulos

- Animaciones suaves al hacer scroll (fade in, slide up)

- Que la página transmita cariño, orgullo y celebración
